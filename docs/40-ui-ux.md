# 40 · UI/UX 设计系统（M4）

> 负责人：ui-ux ｜ 上游：`00-brief` §3–§9 ｜ 配套：`41-motion-responsive.md`
> 基线：**Apple HIG**（触控 ≥44pt → 网页 **48–56 CSS px**、安全区 `env(safe-area-inset-*)`、动态字号、对比度 ≥4.5:1、Reduce Motion）＋ **Material 3**（时长 100/200/300/400ms、standard/emphasized、状态层、高度层级、触觉）。
> 视觉载体：**代码生成的扁平矢量**（KAPLAY 图形 API，无外部图片、无粗糙占位）。归本文件：色/字/距/圆角/描边/层级/断点/组件尺寸/文案/状态；归 41：时长/曲线/震屏/DPR/安全区/触控位置/输入/降级。
## 1. 目标与范围
视觉世界（design POV）：**一张被红笔批改过的黑板**。世界是扁平的、带描边的矢量色块（圆头方身的物化帝、几何化的笑长）；UI 是「贴上去的东西」——黑板绿底板、粉笔白字、红笔批注、奖状金、试卷纸。UI 不做玻璃拟态，用硬描边、硬投影、印章和批注说话。

- **做什么**：11 类组件规格（线框图/逐字文案/全状态）、设计 token、程序化矢量拆解、PC 与移动布局差异、断点表、可访问性、可测验收清单。
- **不做什么**：不写代码、不选型框架、不改 00-brief 的全局数值与固定文案、不打包字体、**不做任何视频制作/剪辑/导出**（PC 与移动端只是同一构建的响应式适配）。

模式定位：游戏世界 = **Experience**（演出优先），UI = **Operate**（瞬时可读、可预期、不抢戏）。共用 token，但 UI 优先可读性：风格化不得降低对比度、字号或命中区。
## 2. 机制 / 规则
**2.1 五条视觉规则（违反即缺陷）**
1. **世界是扁平矢量，UI 是纸/黑板**：世界层只由 KAPLAY 图形 API 绘制（圆、圆角矩形、多边形、线段），统一 **2 逻辑 px 描边**，无位图、无外部图片；UI 文字用系统字体，禁止像素字体。
2. **硬边原则**：UI 阴影 `blur = 0`，只允许右下硬投影；禁止玻璃拟态、渐变底、发光描边（辉光只属于世界层特效与全屏闪白）。
3. **颜色即规则**：红=危险/激光/扣血，黄=暴露/注意，金=货币，绿=成功，白=正文；语义必须同时有形状/图标/数字，不许只靠颜色。
4. **批注只在批改语义出现**：红笔斜线、叉号、圈画、印章只用于「被扣分/被抓住/通关盖章」，不做装饰涂鸦。
5. **一屏一主动作**：每屏只有一个 Primary；危险动作（重开/返回标题）必须二次确认。

**2.2 版面与网格**
- 设计基准 **960×540**；UI 以 **CSS px** 布局并按断点降级，不随 canvas 等比缩放（41 §5.1）；间距全落 **4px 基线网格**，组件内边距 ≥8px，相邻可点击元素间隙 ≥8px。
- 内容安全区左右 16、上 12、下 12，再叠加 `safe-area-inset`（41 §2.6）；对话框/弹层不遮住角色脚下地面超过 40% 屏高。

**2.3 浮层规则**
- 同一时刻最多 **1 个模态**（对话/商店/暂停/失败/结算），HUD 常驻；失败页强制关闭其它模态。
- 浮层打开后 **200ms** 忽略确认类输入；关闭后焦点还原到打开它的控件；模态 `aria-modal` + 焦点陷阱 + 背景 `inert`。
- 对话中不许暂停；商店中 Esc/点遮罩 = 关闭；暂停中再按 Esc = 继续；HUD 只有暂停键可聚焦。

**2.4 文本规则**：全角标点；正文 16/24；数字 `tabular-nums`；金币千分位 `15,000`；价格写 `10 金币`；用时 `02:14`；血量用心形（低血量补 `1/5`）；说话人名 ≤8 全角字、商品名 ≤12 字、超出省略。

**2.5 HUD 常驻组合**：第一关 = 心 ×5 + 金币 + 暴露条 + 道具槽 + 关卡指示；第二关 = 心 ×5 + 金币（开局 `15,000`）+ 道具槽 + 关卡指示。数值变化 1 帧内可见；滚动动效不阻塞读数。

**2.6 程序化扁平矢量拆解（世界层）**
通用：每角色 ≤8 个几何体；2px 描边取自身填充压暗 35%；高光只用一个 40% 透明圆角矩形；不用纹理/噪点；**汉字与 emoji 只做表情/标点（≤24px），不嵌进身体**；渐变仅限背景与 Boss 能量环。世界层扩展色（只允许在此表新增）：校服蓝 `#3D6FA8`、皮肤 `#F2C9A0`、头发墨 `#141B22`、蘑菇青 `#7FB8A4`、西装灰 `#4A5157`。

## 4. 流程 / 状态机
```
Boot → Title ─开始/继续→ LevelIntro(n) → Playing
Playing ⇄ Pause（Esc/⏸/失焦）   Playing ⇄ Dialogue（game:dialogue-start/end）
Playing ⇄ Shop（game:shop-opened）  Playing → Fail（game:fail）→ Retry → Playing
Playing → LevelClear(n) → LevelIntro(2) 或 ToBeContinued
```

| 当前 | 事件 | 下一个 | UI 反应（时长见 41） |
|---|---|---|---|
| Title | 「开始」/「继续」/Enter | LevelIntro | 按下 100ms → 整屏 120ms 淡出；无存档时「继续」禁用 |
| LevelIntro | 3s/点击/任意键 | Playing | 关卡字 300ms 退场，HUD 200ms 淡入 |
| Playing | `game:dialogue-start` | Dialogue | 对话框 200ms 入场，输入锁定 |
| Dialogue | 最后一句/「跳过」 | Playing | 200ms 退场，200ms 后恢复输入 |
| Playing | 商店触发圈 / Esc / 失焦 | Shop / Pause | 弹层 300ms + 遮罩 200ms；暂停遮罩 200ms |
| Shop | 购买成功 | Shop（刷新） | 卡片 400ms 绿边 + 金币滚动 |
| Playing | `game:fail` | Fail | 200ms 冻结 → 400ms 去饱和 → 400ms 覆盖 |
| Fail | 「重试」/R/Enter | Playing（检查点） | 120ms 淡出 + 120ms 淡入 |
| Playing | `game:level-complete` | LevelClear | 行 300ms，stagger 40ms |
| LevelClear(2) | 「继续」 | ToBeContinued | 400ms 入场，主标题 36 |
## 5. 交互与表现
**5.0 全局按钮**

| 变体 | 尺寸/样式 | 默认 | hover（PC） | 按下 | 禁用 | 焦点 |
|---|---|---|---|---|---|---|
| Primary | 高 56，padding 0 24，`--r-12`，chalk 底 + ink 字 16/600，4px 硬影 | 实心 | 上移 1px + 状态层 8% | `translate(2px,2px)`、影缩 2px、100ms | 38%、无影、`not-allowed` | 3px chalk 环 + 2px ink 外环，offset 2px |
| Secondary / Danger / Ghost | 高 48；Secondary 2px chalk 描边、Danger 2px `--c-pen` 红字、Ghost 纯文字 | 描边/文字 | 状态层 8% | 10% + 下移 1px；Danger 填充 pen | 38% | 同上 |

所有可点击元素命中区 ≥48×48（视觉更小则透明扩展补足）；按下同时触发触觉（41 §5.8）；焦点只在 `:focus-visible` 显示。

**5.1 Title**
```
┌──────────────────────────┐
│      物 化 帝 笑 传       │ 36/800
│      物化帝 · 校园篇      │ 14/chalk-2
│   [ 开始 56 ] [ 继续 48 ] │ [ 设置 48 ]
└──────────────────────────┘
```
- 文案：标题「物化帝笑传」；副标「物化帝 · 校园篇」；按钮「开始」「继续」「设置」；页脚 PC 版「v0.1 · A/D 移动 · 空格跳 · Esc 暂停」/触控版「横屏 · 左手移动 · 右手跳跃」；「设置」为纸面弹层（音量/减少动效/控制方案/全屏/关闭）。
- 结构：标题距顶 18vh；按钮组宽 280、间距 12；背景为静止的扁平礼堂剪影（几何色块）+ 黑板底。

**5.2 HUD**
```
┌ safe-top + 8 ─────────────────────────────┐
│ ♥♥♥♥♡  [暴露 ███████░░░ 48%]  🪙 15,000 ⏸ │
│ 第一关 · 笑长  ●○○○              [枪 40]  │
```

## 8. 扩展点
- **加一屏**：注册 `{ id, mount, unmount, focusFirst }`，复用 §5.0 按钮与 §3 token，不改核心代码。
- **加商品**：内容数据加 `shop.<id>`（名称/描述/价格/图标槽/是否一次性），卡片自动生成。
- **加语义色**：只在 §3.1 追加一行并给出 ink/board/paper 三组对比度，无数据不得入库。
- **加语言**：文案集中 `ui-copy`；名 8 字/商品名 12 字截断规则改按 em 宽计算。
- **加设备**：断点表追加一行；触控键位沿 41 §5.3 百分比定位扩展，不硬编码绝对像素。
- **加手柄**：接入 41 §5.7 的 action 抽象即可复用全部界面焦点逻辑。
## 9. 验收标准
- [ ] 所有可点击元素命中区 ≥48×48 CSS px，相邻间距 ≥8px（3 个断点各抽 5 个实测）。
- [ ] Primary 高 56、Secondary/Ghost 高 48，与 §3.4 一致。
- [ ] 320–2560px 宽、横竖屏均无裁切/拉伸，letterbox 居中，比例 16:9。

- [ ] 对比度抽查 8 组：正文 ≥4.5:1、图形/描边 ≥3:1，不达标项为 0。
- [ ] 去色后仍能区分血量满/空、暴露 ≥50%、金币不足、购买成功（图形 + 文字双通道）。
- [ ] 系统字号 200%：对话 ≤4 行可滚、商店可滚、主按钮可点、无横向溢出。

- [ ] 键盘：Tab 顺序合理、模态内不逃逸、Esc 关闭并还原焦点、全流程可只用键盘完成。
- [ ] 触控层在 PC 隐藏、手机横屏显示；商店金币 <10 时「金币不足」禁用并显示还差金额。
- [ ] 暴露条 ≥50% 同时出现斜线 + 暗角 + 百分比；失败页 400ms 内出现且 `sfx.fail` 缺失时只 warn 一次。
- [ ] 暂停：Esc/⏸/切后台均进入且不重复叠加；「重开本关」「返回标题」有二次确认。
- [ ] 结算四项统计正确，第二关后进入「未完待续」；设置 `reduceMotion` 写入存档并在下次启动保留。
- [ ] 无存档时「继续」禁用；存档损坏时提示并新开档；iOS（无全屏/无振动）与 Android 各实测一次，无未捕获异常。
## 10. 风险与待确认
1. **R1 UI 渲染层**：本文件按「UI = DOM 覆盖层、游戏 = canvas」写尺寸与焦点；若 `50-engine-architecture` 定为 canvas 内绘制 UI，§3 的 CSS px 需按 41 §5.1 的 `1/scale` 反算，触控层仍建议保留 DOM。**需 Lead 拍板**。
2. **R2 事件命名**：新增 `ui:*` 六个事件与 `requestPurchase`，需登记进 `02-data-contracts`。
3. **R3 文案归属**：失败页「败了 / 物化帝，这次不算，再来一次。」、商店标题、横向提示为本模块拟定；叙事模块可提替换，定稿后进 `ui-copy`。
4. **R4 字体**：系统字体栈在部分 Android 上 700/800 被合成伪粗体；首版接受（brief 禁止打包字体），若要求统一需用户拍板放宽依赖。
5. **R5 iOS 能力缺口**：无 `navigator.vibrate`、无全屏、无方向锁定，已有降级（41 §5.6），无法与 Android 完全一致，需接受。
6. **R6 矢量细节上限**：每角色 ≤8 个几何体可能不足以表现「假生秒表」等细节，允许在 8–12 之间微调，但不得引入位图。
